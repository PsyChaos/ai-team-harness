## TypeSafe / Jev

Documentation:
https://docs.typesafe.ai/introduction

Official Python SDK:
https://github.com/typesafe-ai/typesafe-sdk-python

Official System One adapter:
https://github.com/typesafe-ai/system-one-adapter-python

The official Python SDK demonstrates `TypeSafeClient.system_one` with typed
`Choice` questions and `TYPESAFE_API_KEY`. The harness uses the native HTTP API
instead of adding the SDK as a mandatory dependency.
