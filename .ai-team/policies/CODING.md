# Coding Policy

- Preserve existing architecture unless the task explicitly changes it.
- Make the smallest coherent change satisfying acceptance criteria.
- Do not perform unrelated cleanup/refactoring.
- Do not add production dependencies without task justification.
- Do not change public APIs implicitly.
- Keep migrations explicit about forward/rollback consequences.
- Do not edit generated files unless repository workflow requires it.
- Report unrelated defects as follow-up work; do not silently absorb them into scope.
